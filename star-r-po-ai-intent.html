01 · Situation
The pain

Users were drowning in menus.

Enterprise app users were drowning in menu-based navigation — too many screens, too many clicks to reach routine actions like updating an obligation or pulling a report.

The product surface was growing faster than the IA could absorb.

01b · Research

02 · Task
The deliverable

Replace menus with intent.

Replace the menu-based UI with an intent-based interaction layer where users describe what they want in natural language and the system maps it to the right action.

03 · Action
What I did

A primary paradigm — not a chatbot.

  • Designed the AI intent-design system from the interaction model up — not a chatbot bolted on, but a primary navigation paradigm.
  • Built an LLM pipeline using the Gemini API with explicit prompt engineering — locking JSON output so each intent reliably mapped to a structured action schema.
  • Defined the intent taxonomy — enumerating every user goal in the product surface and grouping them into resolvable categories.
  • Prototyped directly in the codebase alongside engineers, iterating on prompt quality based on real usage telemetry rather than design reviews.
  • Wrote and published "Intent Design — software that listens to you" (May 2026) to pressure-test the methodology publicly.

05 · Reflection
What I'd do differently

AI features need a test suite.

I would invest earlier in evaluation harnesses — measuring prompt quality with offline eval sets before shipping each intent would have caught two interaction edge cases I shipped and rolled back. Lesson — AI features need a test suite, not just a design review. Prompts are interface contracts, and contracts without tests rot in production.
