01 · Situation
The pain

The bottleneck was application craft, not jobs.

After 47 job applications and only 2 interviews, I knew the bottleneck was application craft, not job availability.

Tailoring each cover letter and resume to a JD was taking 40+ minutes, and the output still felt generic enough to land in the reject pile.

02 · Task
The deliverable

Generate tailored apps — preserve voice.

Build an AI pipeline that takes a JD plus my raw experience and generates a tailored application that preserves my voice — without me re-writing from scratch every time.

03 · Action
What I did

JD signals in. Voice-preserved output.

  • Designed the prompt architecture in Notion, mapping JD signals — role, tone, must-haves — to specific application sections.
  • Built the pipeline using the Gemini API with prompt chains that enforced my voice via a Notion-managed style guide loaded as system context.
  • Prototyped the UI in Figma and shipped a working surface in Framer with the pipeline wired in.
  • Conducted user interviews with other job-seekers to test whether "preserve voice" was a generalizable goal beyond my own.
  • Iterated prompt quality based on which applications got replies — letting the output funnel drive prompt design, not the other way around.

05 · Reflection
What I'd do differently

Output quality over throughput.

I optimized for speed before optimizing for personalization signal quality, so early versions generated faster but blander applications. Lesson — in AI pipelines for personal voice, output quality matters more than throughput. A 30-minute application that gets a reply beats a 5-minute one that doesn't.
