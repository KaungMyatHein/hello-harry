# Script: Tokens — "Unified design tokens."

**Duration:** ~45 seconds (~110 words)
**Word count:** 110

## Script

At Raytail, every design release came with eight to twelve small mistakes. Different engineers were writing the same color or font name in slightly different ways — one for the website, one for the iPhone app, one for Android. They spent two to three hours every release just cleaning up the names.

So I built a Figma plugin. Designers export the style values once, and the plugin writes them out the right way for each platform automatically. Six different formats from one source. Naming mistakes dropped to zero.

The plugin is free on Figma's community today, and three engineering teams are using it.

If you're hiring me to build tools that make designers and engineers work better together, this is the project.
