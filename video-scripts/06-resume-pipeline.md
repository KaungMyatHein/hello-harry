# Script: Resume Pipeline — "47 apps. 2 interviews."

**Duration:** ~45 seconds (~110 words)
**Word count:** 110

## Script

One designer I interviewed had sent 47 job applications and got just 2 callbacks. Every night, the same routine — paste the job ad into a doc, highlight keywords by hand, ask ChatGPT to rewrite something, half-reject what came back because it didn't sound like her. Eleven of the twelve designers I talked to had the same story.

So I built a pipeline that compares the job ad to the resume, shows what's missing, and suggests rewrites the designer approves bullet by bullet. Forty minutes per application became fifteen. In two weeks of using it, that same designer sent five tailored applications and got two callbacks.

If you're hiring me for AI tools that help people, not replace them, this is the project.
