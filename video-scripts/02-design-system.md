# Script: Design System — "Three platforms, one truth"

**Duration:** ~40 seconds (~95 words)
**Word count:** 95

## Script

At Raytail, changing one brand color used to take the team two days, and they'd still miss screens. Three apps — the cash register, the website, and the mobile app — were each writing the same color value in their own way.

So I rebuilt how all the colors and styles are stored. One place feeds all three apps. Two-day changes now take an hour. We dropped 47 duplicate styles down to zero.

If you're hiring me to clean up a messy design system, or build one from scratch, this is the project to look at.
