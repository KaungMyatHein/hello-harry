# Script: Pharmacy POS — "Two stores. One system."

**Duration:** ~45 seconds (~110 words)
**Word count:** 110

## Script

This one was for STO Peoples Choice — a pharmacy chain and a supermarket chain in the Maldives. Both stores were running on the same decade-old cash-register system that was about to die. They wanted one new touchscreen system that could run both. The hard part — pharmacies need extra safety checks, like supervisor sign-offs on big actions and a record of who did what.

So I designed the stricter pharmacy version first, then turned the extra checks off where the supermarket didn't need them. One designer, 14 sections, more than 200 screens. Today it's running in about 20 stores across both businesses.

If you're hiring me for big enterprise software, especially where one designer has to own everything, this is the project.
