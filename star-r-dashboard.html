01 · Situation
The pain

A 5-tool ritual eating 90 minutes a day.

Finance analysts were running a daily ritual across 5+ separate tools — checking dashboards, exporting data, cross-referencing in spreadsheets.

The context-switching was eating roughly 90 minutes a day per analyst.

02 · Task
The deliverable

Consolidate the ritual into one tab.

Consolidate the multi-tool daily ritual into a single workflow that surfaced the right data in the right order, eliminating the tool-switching tax.

03 · Action
What I did

Shadowed first. Designed second.

  • Shadowed analysts through their morning ritual, logging every tool open, query run, and copy-paste — building a real workflow trace, not a stated workflow.
  • Mapped data dependencies into a single information architecture so the dashboard mirrored the analyst's mental model, not the underlying tool boundaries.
  • Designed the dashboard in Figma with data viz primitives chosen for at-a-glance scanning — because the morning ritual was time-boxed.
  • Quantified projected time savings before build to lock the ROI commitment with stakeholders, not after the fact.
  • Validated the design with the same analysts I had shadowed, iterating until each could complete their ritual in one tab.

05 · Reflection
What I'd do differently

Don't punish the deep-dive.

I designed for the morning ritual but didn't account for variation in afternoon work — the dashboard solved the high-frequency case beautifully but felt cramped for exploratory deep-dive analysis. Lesson — dashboards that nail the daily ritual sometimes punish the deep-dive. Design for both modes explicitly, or be honest about which one you are not serving.
