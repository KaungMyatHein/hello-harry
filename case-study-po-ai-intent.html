01 — The Problem

"Show me past 2 weeks." The Dashboard Couldn't.

A Myanmar live-seller has one question every Sunday: what did I sell in the past 2 weeks? One sentence. Clear intent.

The CRM dashboard turned that one sentence into a five-step hunt — and most sellers gave up halfway.

  • Open — Orders tab, buried two levels deep
  • Filter — no "past 2 weeks" preset; pick start & end dates manually
  • Translate — every label in English, sellers think in Myanmar
  • Scroll — 600 rows, no summary at the top
  • Give up — rebuild the answer in Excel by hand
The seller already knew the question. The system made them prove it.

03 — The Classifier

Regex First. AI Last.

Pure TypeScript function. No LLM call. No network.

~1–3s · rare
No match → AI fallback
  • Latency — card renders before finger lifts off enter
  • Cost — no API call per keystroke
  • Determinism — regex is auditable. LLMs fail differently every time
03b — Inside the Regex

How a Sentence Becomes an Action.

Each rule is a regex family + a capture function. Ordered by specificity — most specific first.

Extract parameters function classify(query) { const m = query.match(customerOrdersRe); if (m) return { kind: 'list-orders', customerName: stripParticles(m[1]), behaviour: 'inline' }; // ...next rule }

Three things every rule does:

  • Match — does the query fit this shape?
  • Capture — pull out productId · customerName · status · range
  • Normalise — strip particles, convert MM digits, lowercase
Specificity beats cleverness. "Khin Hnin's orders" must match before plain "orders."
04 — Bilingual Matching

Myanmar Isn't English in Different Glyphs.

Myanmar glues grammar particles onto the noun — possession, subject, plural. No spaces. No apostrophes. No cues for a Latin-tuned regex.

English
"show me pending orders"
↓ matches
list-orders · status=PENDING
Myanmar
"လက်ကျန်အော်ဒါတွေပြပါ"
↓ matches
list-orders · status=PENDING
Mixed
"pending order ပြပါ"
↓ matches
list-orders · status=PENDING
  • Possessive stripper — pulls bare names out of MM particles + EN 's
  • Subject-marker parser — handles "[name] [marker] [verb]" purchase queries
  • Digit normaliser — Myanmar digits (U+1040–U+1049) → ASCII

One URL. Two Surfaces Agree.

Reflection

What I Learned

01 — A command palette isn't a UI pattern. It's a contract.

The seller speaks naturally; the system promises to meet them there.

02 — Don't pretend Myanmar is "English with different glyphs."

Postpositions, subject markers, and stacked digits need first-class support — not retrofits.

03 — Matching intent is half the problem.

Matching the user's expectation of the result is the other half. Ranking ≠ enumeration.

04 — Regex is a feature, not a fallback.

Predictable behaviour is itself a way of reducing what the user has to learn. The LLM is the rare path.
