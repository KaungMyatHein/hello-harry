01 — The Handoff Tax

Every Handoff
Loses Intent.

A design system reduces the loss. A token pipeline reduces it more. But layout — the relationship between elements — still leaks at the seam between Figma and code. A spacing decision becomes "8 or 12, eyeballed." A weight contrast becomes "close enough."

The Design System work fixes the vocabulary. The Tokens plugin ships that vocabulary to code. Orchestra goes one layer further: it asks what happens when the canvas itself is the published artifact — no exporter in between.

"The handoff isn't where the bug lives. The handoff IS the bug."

Orchestra is named for the relationship between elements — type, space, weight — performing together. Compositions don't survive translation. So I stopped translating.

02 — Canvas Is the Source

Tokens Flow In.
The Site Flows Out.

Same logic as the Tokens plugin — the canvas owns the truth — applied to publishing instead of components. I authored everything in Figma Sites: variables, type ramps, spacing scales, layout primitives. Then published the canvas as the live URL. No exporter, no developer-facing JSON, no translation step.

What I designed is what shipped. Pixel-for-pixel. Token-for-token.

Pipeline collapse
  • Variables stay variables — not "approximate values"
  • Spacing tokens stay exact through publish
  • One round-trip: canvas edit → live URL
The trade
  • Type roster is constrained to Figma's web-safe set
  • No bespoke interaction logic — only declarative state
  • Rich media (video, embeds) needs workarounds
03 — Composition Primitives

Rhythm, Weight,
Whitespace as Tokens.

If the canvas is the source, the design language has to be tokenised the same way colors and spacing already are. I codified three primitives — not as theory, as reusable canvas patterns. Each one works the way a semantic token works in the Design System: composable, named, swappable.

Rhythm
A vertical cadence token — applied across sections so spacing reads as intentional, not arbitrary.
Weight
Type-size + tone pairings as a single decision. Hierarchy without arrows or labels.
Whitespace
Negative space sized in tokens, not vibes. Empty space is a design element, not absence.
04 — Publishing

The Design IS
the Code.

There is no exporter. There is no GitHub. There is no developer reading my Figma comments and approximating them in TSX. The canvas, with its variables and tokens intact, is what serves at the URL.

It's a smaller pipeline than what shipped Pharmacy POS or the Raytail Design System — but it's the only one with zero translation loss. For a site whose whole point is composition, that's the right trade.

What worked
  • Edit-to-live cycle measured in seconds, not sprints
  • Token integrity preserved end-to-end
  • Composition decisions reach users intact
When it doesn't fit
  • Anything that needs auth, state, or backend
  • Multi-platform (web + iOS + Android) — use the Tokens plugin instead
  • Sites with bespoke interaction systems
05 — Reflection

Where Orchestra
Sits in the Pipeline.

Orchestra is one of three pieces I treat as a single arc on design-to-dev. Each one solves a different part of the same problem: how does design intent reach users without losing itself in translation?

01 — Design System defines the vocabulary.
Three-tier tokens (primitives → semantic → component) and governance rules that prevent drift. This is the shared language the other two pieces depend on.
02 — Tokens plugin ships that language to code.
Six platform formats from one source. The pipeline that lets a multi-platform team consume design decisions without manual translation.
03 — Orchestra collapses the pipeline entirely.
For surfaces where the composition is the product — marketing sites, manifestos, design portfolios — the right pipeline is no pipeline. Canvas to URL, single action.
04 — Pick the smallest pipeline that survives the constraint.
Multi-platform product? Tokens plugin. Three platforms with shared library? Design System. Single canvas-driven site? Orchestra. The lesson isn't "always collapse" — it's "every translation step is a place intent goes to die." Use the fewest you can get away with.
